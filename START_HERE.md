## 🆘 Need Help?

### Build Issues?
- Check: `QUICK_START_MOBILE.md` troubleshooting
- Clean build: `cd android && ./gradlew clean`
- Rebuild: `npm run build && npm run mobile:sync:android`

- Verify `google-services.json` exists
- Check SHA-1 fingerprints added
- Rebuild after Firebase changes
