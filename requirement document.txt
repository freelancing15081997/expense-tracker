# 11. ACCOUNTING ENGINE

This is the heart of Books.

Implement a reusable accounting engine.

Every financial posting must eventually generate balanced journal lines.

Fundamental invariant:

```text
SUM(debit) = SUM(credit)
```

Use:

```text
NUMERIC / DECIMAL
```

for monetary values.

NEVER use floating-point numbers for financial calculations.

The frontend must NEVER be the source of accounting truth.

Backend must:

* calculate
* validate
* round
* verify
* post
* persist

all accounting-critical values.
